Skin Disease Image Classification Using Machine Learning

A deep learning computer vision system trained on authentic dermatoscopic skin lesion imagery from the International Skin Imaging Collaboration (ISIC HAM10000) archive. Demonstrates automated image preprocessing, convolutional feature learning, multi-class classification, and leak-free model evaluation.

⚠️

Important Educational & Research Disclaimer

This application is strictly an educational computer science demonstration and an academic machine learning mini-project. It is NOT a medical device, nor a clinical diagnostic instrument. The predicted class label and model score reflect pattern similarity within a localized scientific benchmark dataset, not confirmed patient diagnoses. Any skin lesion concern requires evaluation by a licensed dermatologist or medical professional.

    🔄 Fig. 2 — Image Preprocessing Pipeline

    Rigorous preprocessing transforms raw, variable-sized clinical photographs into normalized tensors ready for convolutional feature extraction:

    Preprocessing Steps:

    1. Folder & Class Detection: Dynamically loads images organized in directory hierarchy.
    2. RGB Enforcement: Ensures 3 color channels, discarding unnecessary alpha channels.
    3. Resolution Standardization: Resizes images using bilinear interpolation to 128 × 128 pixels.
    4. Tensor Normalization: Scales pixel values from [0, 255] into continuous float [0.0, 1.0].
    5. Data Leakage Prevention: Groups images by lesion/patient ID so train and test sets remain strictly disjoint.

    Training-Time Data Augmentation:

    To enhance generalization across skin tones, rotations, and lesion orientations, the following transformations are applied exclusively during training:

    • Random Horizontal & Vertical Flips
    • Random Rotation (up to 12% range)
    • Random Zoom (up to 10% factor)
    • Validation and Test sets remain strictly unaltered.
